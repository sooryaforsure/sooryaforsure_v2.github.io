# Sooryathej K L - Portfolio

A modern, responsive personal portfolio website built with React, Vite, and Tailwind CSS. The design was generated using Figma Make and features a terminal-inspired aesthetic.

## Features

- **Hero Section**: An interactive, terminal-themed introduction with mouse-tracking glow effects and a typewriter code block.
- **About**: A brief introduction to my background and goals as a Software Developer and MCA student.
- **Projects**: A showcase of my work, including a smart Socratic Duck assistant.
- **Skills & Tools**: A grid layout displaying my technical stack (Languages, Databases, Devops, Platforms, Design).
- **Contact**: A fully functional contact form powered by Web3Forms for seamless communication.

## Running Locally

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. Open your browser and navigate to `http://localhost:8443` (or the port shown in your terminal).

## Deployment
You can build the production assets by running `npm run build` and hosting the generated `dist` folder on Vercel, Netlify, or GitHub Pages.
